# SDDS Technical documentation

This site contains technical documentation for the Smart Data Donation Service which is
cross-service. Documentation for specific GitHub repositories may be found within the repositories
themselves.

## Architecture Decision Records

We use [Architecture Decision Records](./adr/) (ADRs) to record our technical decisions and the pros
and cons considered as part of each decision.
